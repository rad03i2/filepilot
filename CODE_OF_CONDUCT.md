# Code of Conduct

FilePilot is a small open-source utility project. Discussions and contributions should stay respectful, practical, and focused on improving the software.

Expected behavior includes constructive technical feedback, respect for different experience levels, protecting user privacy, and using generated sample files instead of personal data.

Unacceptable behavior includes harassment, publishing private data, posting credentials or personal documents, misleading claims about recovery guarantees, or encouraging destructive behavior without clear user control.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md).
